How to Run and Test the Extraction Pipeline
===========================================

This document explains how to run the pipeline, specifically highlighting the new Exact 3D Mesh Reconstruction pipeline for CAD drawings (DXF).

## 1. Environment Setup

If you haven't already:
```bash
# Activate the virtual environment
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```
*(Note: manifold3d and trimesh were added to support 3D mesh generation)*

## 2. Run the FastAPI Server (Backend & UI)

Start the application:
```bash
uvicorn app.main:app --reload --port 8000
```

Once running, you can access the frontend UI in your browser:
**http://localhost:8000/ui**

To explore the interactive API docs:
**http://localhost:8000/docs**

## 3. How to Test the 3D Mesh Reconstruction

1. In the Swagger UI (http://localhost:8000/docs), find the **POST /api/v1/extraction/process** endpoint.
2. Click **Try it out**.
3. Upload a DXF file (e.g., a pressure vessel drawing).
4. Click **Execute**.

### What Happens:
When a DXF file is processed, the pipeline now executes the exact reconstruction logic:
- `dxf_reader.py`: Parses the exact CAD entities (ignoring pixels/heuristics).
- `reconstruct.py`: Identifies the axisymmetric solid cross-section and any sub-features (like tap holes).
- `mesh_builder.py`: Uses `manifold3d` CSG to revolve the exact faces and export a 3D model.

### Where to Find the Output:
The extraction results are saved to the `data/outputs/{job_id}/` directory:
- `vessel_geometry.json`: The structured JSON metadata (dimensions, parametric segments).
- `mesh.glb`: The **Exact 3D Mesh** generated from the CAD geometry. You can drag and drop this file into any 3D viewer (like Windows 3D Viewer or an online GLTF viewer).

## 4. Run the Test Suite

To verify the extraction pipeline programmatically:
```bash
pytest tests/ -v
```
